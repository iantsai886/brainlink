## Current working-tree update (2026-10-25)

This branch adds a separately confirmed remote-conflict-copy action. It re-fetches and privacy-filters remote notes, accepts only paths still classified as conflicts, and saves remote content to a deterministic `BrainLink Conflicts/<path>.remote-<sha256-prefix>.md` copy. The local version is never overwritten. Parent directory creation rejects symlinks and non-directories; identical retries are idempotent. English, Portuguese, and Traditional Chinese UI strings are included. `docs/CHATGPT-CODE-CONTRIBUTOR-PROMPT.md` defines a non-overlapping held-out retrieval/token-efficiency evaluation for a separate Codex contributor.

Validation on Windows with Node 24.18.0: `npm run test:all` completed successfully: core 294 tests (288 passed, 0 failed, 6 skipped), UI 28 tests (28 passed, 0 failed). Focused GitHub and locale tests passed 15/15, including the authenticated Setup endpoint. These tests use fictional vaults and local bare Git remotes. The demo Setup page was visually opened, but browser automation stopped before the GitHub section could be inspected; no live GitHub account or remote repository was used. The change is not cross-client validated or release-ready.

The prior full-suite baseline includes the RSI-ledger changes, GitHub selected-commit push, remote-advance refusal, and add-only remote-note import. Current conflict-copy behavior is recorded above. Tests use fictional vaults and local bare Git remotes; live account authentication and cross-device behavior are not validated.

This is an evidence ledger, not a release-readiness claim. “Implemented and locally tested” does not imply packaged, cross-client validated, or ready for customers.
