Your knowledge stays yours.
AI gets the access you choose.

BrainLink connects your Markdown or Obsidian vaults to AI apps through named roles and permission profiles. It searches for relevant notes, returns a limited cited answer context, and keeps proposed changes under your review.

01 · Architecture

One local hub between your files and AI apps

BrainLink is the permission-aware middle layer. Vaults remain in their folders; each AI receives only what its assigned profile allows.

User-owned filesBrainLink servicePermission boundaryPrivate finance role

When a connected cloud AI answers, BrainLink sends it the excerpts the request is allowed to retrieve. A local vault does not mean every AI provider is local.

02 · First setup

Connect folders, define roles, assign AI apps

Adding a vault registers its folder with BrainLink. It does not automatically give every AI access.

Choose a vault

Select an existing Obsidian or Markdown folder. BrainLink indexes it without moving the notes.

Set privacy

Mark private vaults, set exclusions, and keep private finance away from company material.

Create a role

Name the role, define what it does, and set its activation phrase, such as “Connect to John.”

Choose a profile

Make a Personal, Organisation, or Client boundary with specific vaults and allowed actions.

Connect an AI

Give that app its own BrainLink identity, check access locally, then start a fresh AI session.

Plain-language shortcut: a role is who the AI acts as; a profile is what that AI is allowed to see and do.
03 · Profiles and permissions

A profile is an app’s access pass

Each AI connection gets a scoped identity. The profile checks apply before BrainLink returns search results or note text.

AI app asksA named role and a request, such as a question about a decision.
→
Identify the appIts BrainLink key identifies the connected AI identity.
→
Check its profileAllowed vaults, operations, memory types, and role are checked.
→
Return allowed contextOnly matching notes or excerpts are returned. A denied scope fails closed.
A

Role: “Who am I?”

A role gives an AI its name, purpose, activation phrases, and saved context. Examples: Anna for Iango coordination; John for Ian’s personal finance.

P

Profile: “What can this app access?”

A profile assigns a connected AI identity to vaults and actions. One app identity belongs to one Twin profile at a time, so it cannot silently mix Personal and Organisation memory.

Access actions are separate choices

Search
Find matching notes in an allowed vault.
Read note
Open a specific allowed note, usually after search finds it.
Propose note
Prepare a new note draft for review; does not grant direct writes.
Session history
Read prior AI session summaries only when separately enabled.
Handoff
Read or send task updates only with a separate handoff grant.
04 · Questions and retrieval

From a question to a cited answer

BrainLink aims to bring back the smallest useful context first rather than dumping a whole vault into the chat.

Ask

You ask the AI a question or activate a role.

Scope

BrainLink checks the AI identity, role, profile, vault, and allowed action.

Search

It ranks matching notes while filtering excluded and private content.

Context

It returns short excerpts with note names, paths, and dates for citation.

Answer

The AI uses the supplied evidence and can request a specific note if needed.

A no-result response means the search did not find a confident match; it is not proof that no relevant note exists. The AI should not guess missing details.

07 · Continuity

Memory and sessions have different jobs

BrainLink groups saved knowledge into four memory types so apps can request only the kinds of context they are allowed to use.

W

Working

Current tasks, open loops, and handoff status.

S

Semantic

Facts, decisions, concepts, and relationships.

P

Procedural

Roles, policies, and reusable methods.

E

Episodic

A record of a particular session or event.

Handoffs

An agent can pass a task to another only through the configured mailbox and with separate read/send permissions. The status trail is append-only.

Session capture

Access to session summaries, logging, and full text are separate permissions. Private closeouts are proposed for review; transcript content is not automatically shared.

08 · Other parts

Navigation, backups, and background work

These features support the knowledge flow; each has its own scope or opt-in control.

3D

Notes and graph

Browse and search notes, inspect links, and explore typed relationships. The combined graph excludes private vaults. A private vault can be opened separately in its local-only graph view; note-level private flags and excluded folders remain hidden.

B

Briefs and open loops

A brief summarizes recent changes from one chosen vault. Private-vault briefs stay in the local app and are not written into the vault.

↻

Backup and restore

Backups can include private notes. Choose a destination and schedule; encryption is optional. Keep the recovery key safely stored elsewhere if encryption is on.

⇄

Sync

BrainLink can use a folder already synced by your cloud-drive app. Private vaults and sessions are excluded from BrainLink sync.

◎

Activity and health

See which tools were called and whether they succeeded. Activity summaries use tool names and outcomes, not note contents.

↑

Improve / RSI

Optional reviews and experiments create proposals. They do not rewrite the product, change permissions, or promote themselves.

09 · Keep boundaries clear

What stays separate

Think of every app connection as an access pass, not a company-wide master key.

✓

Private vaults

Private vaults stay out of the shared graph, sync, and source scanning. A local-only graph view can show one selected private vault without combining it with public vaults.

✓

Excluded folders

Excluded folders are skipped by indexing and search; they are also omitted from graph views and ingestion.

✓

Separate AI connections

A profile-scoped app identity has one profile at a time. Moving an app to another profile changes what that app can access.

✓

Private finance

John works in Ian Personal. Anna works in Brain. A financial recommendation is not permission to trade, move money, or make a commitment.

Cloud AI note: when BrainLink returns a private-note excerpt to a cloud AI app, that excerpt is then available to the provider powering that app. Only connect a vault when that data path is acceptable.
