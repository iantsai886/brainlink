BrainLink by Iango · Product preview

One governed memory layer for your AI tools.

BrainLink connects selected Markdown vaults to supported AI clients. You set which vaults and actions each client can use. Agents can retrieve cited context, hand work to another agent, and prepare notes for your review.

The problem

Each AI starts from zero, and the ones that can write make a mess

AI tools often start without the context from your other work. BrainLink keeps selected notes in your vault, filters retrieval by each client's permissions, and provides source links so work can continue with the right context.

You, in a connected AI"Connect to Chief of Staff"If that role and its procedural memory are enabled, the AI receives the allowed role notes and current context. Older sources can be flagged.
You, in another connected AI"What did we decide about the launch?"The other AI searches only its assigned vaults and can cite the note it found.
You, at the end"Chief of Staff close loop"BrainLink prepares an attributed summary and asks for review before saving, unless you separately enabled a private draft route.

Safe by design

Your rules are enforced in software, not left to a prompt

No silent overwritesAI note tools create new notes or append to an approved target; they do not replace an existing note.
Review before savingNote proposals show a preview and require separate approval. Optional closeout drafts stay private and unverified.
Clear attributionSaved notes can record the AI, agent, session, source and time.
Secret checksBrainLink scans proposed content for common secrets and blocks flagged text; this check cannot guarantee that every secret is detected.
Scoped accessAssign each AI a Twin profile, specific vaults and allowed actions. Private content is filtered before retrieval.
Local firstBrainLink does not upload vaults to Iango. When you use an AI provider, it may receive the context you ask BrainLink to retrieve.
Smart by default

Linked knowledge with review and source context

BrainLink can suggest organization and connections. You can inspect the source and review proposed graph links.

Suggested note linksNew notes can include links to visible notes by name and related terms.
Search optionsUse keyword search and filters. Optional local embeddings can add meaning-based results.
Compact cited contextAgents receive short excerpts with source links first. On a 30-case fictional test, estimated tool-result tokens were 27.5% lower than compact search with the same task score and source recall. Provider-billed savings are not measured.
"Brief me"What changed this week, open tasks, next actions and decisions waiting on you, in one answer.
Saved memoriesAuthorized agents can receive saved facts when semantic memory and vault access are enabled for their profile.
Meeting notes from transcriptsPaste a transcript and get a meeting note with attendees linked and action items as tasks.
Shared commands and SkillsVersioned prompts and Agent Skills can be installed for supported clients, subject to each client's own discovery and reload behavior.
Getting started

Choose what to connect and what each AI may use

  1. Install and open

    Run the installer. The BrainLink shortcut opens its local Setup screen.

  2. Select vaults and access

    Choose your Markdown folders, Twin profile, memory types and the actions allowed for each AI client.

  3. Connect and check

    Connect each supported client, follow its reload instructions, then confirm BrainLink tools appear before using them.

Product status

Development preview

The current development build has no trial countdown or licence gate.

Pricing, paid plans and a commercial release date have not been announced. The development build is not a signed commercial release; supported clients and operating systems still require the validation described in the project status record.

Build targetsWindows, macOS and Linux packages are maintained. Package signing and complete install acceptance across operating systems are still release work.
ConnectionsSupported clients connect through local MCP. Remote access requires a separately configured secure HTTPS relay; local access does not make a remote AI reachable.
Your filesMarkdown files stay in folders you choose. A cloud drive may store those files under its own service terms, and AI providers may receive retrieved context.
