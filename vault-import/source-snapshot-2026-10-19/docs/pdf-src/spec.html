1. Purpose and scope

BrainLink is a desktop application and local Model Context Protocol (MCP) server that gives every AI app a shared, rule-enforcing view of one or more Markdown / Obsidian vaults. It provides ranked search, safe attributed writes, configurable agents with activation and close-loop phrases, and an optional inter-AI mailbox.

In scope (v1): macOS and Windows desktop; stdio and local HTTP MCP transports; Setup UI; one-click client configuration; offline licensing; installers. Out of scope: iPhone/iPad, hosted relay, embeddings, auto-update, MSIX, team sync.

Design goals: (1) notes never leave the machine; (2) no write can destroy existing content; (3) behaviour is identical across AI vendors; (4) nothing in code is specific to a person, company, vault or timezone; (5) install in under 3 minutes.

F-16Support read-only and vault-scoped connections via environment variables.

4.2 Resources and prompts

  • Resource brainlink://guide (JSON guide) and one brainlink://vault/{vault}/{file} per configured read_first rule file. Only published rule files are readable.
  • Prompts per agent: connect-<agent> and close-loop-<agent> (optional argument focus).

4.3 Methods handled

initialize, ping, tools/list, tools/call, resources/list, resources/templates/list, resources/read, prompts/list, prompts/get. Notifications (no id) get no reply. Batches are supported. Unknown methods return -32601; invalid requests -32600; parse errors -32700; internal errors -32603.

5.2 Frontmatter schemas

standard: type, status (default proposed), ai_platform, agent_or_role, session_or_task_id, written_at, source, confidence, tags, plus extra_fields.

provenance: type, status, tags, extra_fields, created_by_platform/agent/session_or_task_id/date, last_material_revision_by_platform/agent/session_or_task_id/date, provenance_confidence (verified | reported | inferred | unknown), source.

5.3 Note body template

Frontmatter; # Title; **Made by {platform} ({role}).**; a notice that other AI platforms also write the vault; optional ## Decision; body; ## Changelog with the creation line.

5.4 Data directory

macOS ~/Library/Application Support/BrainLink; Windows %APPDATA%\BrainLink; other $XDG_CONFIG_HOME/brainlink. Contents: config.json, setup-token (0600), activity.log (JSON lines, rotated at 512 KB to .1), client-config backups. Override with BRAINLINK_HOME or BRAINLINK_CONFIG.

6. Detailed behaviour

6.1 Search

  1. Each Markdown note is parsed (frontmatter, headings, links) and split into heading-aware chunks with ancestry.
  2. Explicit [[Note]] mentions in the query are returned first (match: mention). A bare title is accepted only if unique.
  3. Remaining chunks are scored with BM25 (k1 = 1.2, b = 0.75), boosted by link-graph relations and title matches. Superseded or archived notes (by path, status or superseded_by) are demoted and marked historical.
  4. Results are de-duplicated per note and limited to the requested count.

6.2 Write pipeline (all write tools)

  1. Resolve identity (call arguments, else environment). Platform must be a short name without newline or colon.
  2. Checks: connection not read-only, plan allows writes, vault write mode not off, source present, secret scan clean.
  3. Validate title (non-empty, one line, at most 120 characters, no / \ : # * ? " < > | *), body, folder exists, folder not protected, decision valid if required.
  4. Build content. If the target exists, refuse. If the vault is proposal-only or confirm is false, return the preview and the next step. Otherwise write with an exclusive-create flag.

Secret scan detects API-key and token formats, card/account-like digit runs (13–19 digits), and long token-like strings (40+ base64 characters).

6.3 Agents

Connect: resolves the agent, reads connect notes (excerpt up to 1,800 characters), tail notes (last 1,500 characters), recent dated notes, and the latest captures; returns warnings for missing or stale sources, and instructions to confirm role and scope briefly and not start new workflows.

Close modeTargetResult
append-sectionpathAppends a dated section: Source/date, platform/agent/session, Decisions, Actions taken, Corrections, Unresolved questions, Confidence, Privacy boundary, Links (as wikilinks), Smallest next actions, Decision needed.

append-taskpathAppends task lines - [ ] date — task — next — approval — source/confidence.

Close requires confidence, at least one decision or action (task list for append-task), and an existing target folder. The user's close phrase authorises confirm=true.

6.4 Handoff mailbox

Files match YYYY-MM-DD-HHmm-from-{platform}-to-{recipient}-{slug}.md. Frontmatter includes status (default REQUEST), priority, subject, decision_needed, deadline and ack_of. Listing sorts newest first and returns a 300-character excerpt.

8. Setup UI and API

A local HTTP server on 127.0.0.1 (fixed port 47800, falling back to a free port) serves ui/index.html. Access needs the saved setup token (query parameter t) and a valid Host header. The server quits after 30 minutes idle when launched from the app.

11. Known limitations and open items

  • Apple Developer ID certificates and notarisation not yet done; Windows installer untested.
  • Payment webhook that issues keys automatically is not built; keys are issued with tools/license-issue.mjs.
  • EULA needs legal review.
  • No auto-update, embeddings, hosted relay or team sync in v1.
  • ChatGPT connector access requires the customer to provide their own HTTPS tunnel (optional, outside the product).
  • Secret scan is pattern-based and may miss unusual secrets or flag long non-secret strings.
