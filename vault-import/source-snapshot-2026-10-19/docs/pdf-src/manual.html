1. What BrainLink does

BrainLink turns a folder of Markdown notes (for example an Obsidian vault) into one shared memory for all your AI apps. Claude Desktop, Claude Code, ChatGPT Codex, Cursor, Gemini CLI and Windsurf can all search the same notes, and can add to them under strict rules.

  • Your notes stay on your computer. BrainLink runs locally and has no cloud service.
  • Nothing is overwritten or deleted. AIs can only create new notes or append to a log.
  • You approve writes. An AI shows a preview first; only your approval (or your own close phrase) saves it.
  • Every write is signed with which AI wrote it, in what role, when, and from which session.

3. Installing

macOS

  1. Open BrainLink-1.0.0.pkg and follow the installer.
  2. It installs BrainLink.app in Applications and the brainlink command in /usr/local/bin.
Test builds that are not yet notarised by Apple show a warning. Right-click the installer and choose Open, then confirm.

Windows

Run BrainLink-Setup-<version>.exe. It installs for your user only and needs no administrator rights. The Windows installer has not yet been tested on a real Windows machine; report any problems to support.

4. First-time setup

Open BrainLink from Applications or the Start menu. The Setup page opens in your browser at an address like http://127.0.0.1:47800/. It works only on your own computer and uses a private token, so keep that tab's address to yourself.

  1. Choose your vault folder. Press the folder button, or paste the path. BrainLink counts your notes.
  2. Choose a rule pack (see below).
  3. Name your agent, for example "Max". The phrases become "Connect to Max" and "Max close loop".
  4. Connect your AI apps (section 5).
  5. Test. Ask your AI "Connect to Max". Setup shows a live call log so you can see it work.

You can also try the bundled sample vault, "Acme Studio", from Setup first. It contains no real data.

Rule packs

PackBest forWhat it creates
SimpleOne person, one vaultA BrainLink/ folder with an Inbox, a role note and a session log. Default agent name: Brain.
Founder OSA company vault with an operating agentKnowledge Intake, an office folder with role note, current goal, session captures and an inter-AI Handoffs mailbox, plus an AGENTS.md rules file. A pack only adds folders and notes that are missing. It never changes existing files, and you can edit all of it afterwards.

Command-line equivalent: brainlink init --vault ~/Notes --pack simple --agent Max.

5. Connecting your AI apps

In Setup, press Connect next to each detected app, or Connect all. BrainLink adds itself to that app's MCP settings and saves a timestamped backup of the previous file first. It refuses to touch a settings file it cannot read. Then restart the app.

AppSettings file BrainLink editsAfter connecting
Claude Desktopclaude_desktop_config.json (in the app's support folder)Quit and reopen the app.
Claude Code~/.claude.jsonStart a new session; run /mcp to check.
Cursor~/.cursor/mcp.jsonTurn it on under Settings, then MCP if needed.
ChatGPT Codex~/.codex/config.tomlStart a new Codex session.
Gemini CLI~/.gemini/settings.jsonStart a new session; run /mcp.
Windsurf~/.codeium/windsurf/mcp_config.jsonRefresh MCP servers in settings.

To remove BrainLink from an app: brainlink disconnect <app>. Check status with brainlink clients.

6. Daily use

6.1 Wake your agent

In any connected AI, say "Connect to Max" (use your agent's name). The AI loads the agent's role, its key notes, recent captures and warnings about notes that have not changed for 14 days, then confirms in a few lines what it can do. It will not start new work unless you ask.

6.2 Ask questions of your notes

Just ask: "What did we decide about pricing?" The AI searches your vault, reads the relevant notes and cites the vault and note title. Search ranks notes by relevance, favours notes that link to each other, and demotes notes marked superseded or archived (it tells you when a result is historical). Writing [[Note Name]] in a question pulls that exact note in.

6.3 Save what was learned

Ask the AI to save a note, for example "Save this idea as a note". It shows a preview with the title, frontmatter and text. Reply "yes" and it is saved as a new file named YYYY-MM-DD — Title.md in your intake folder (or another existing folder). Existing files are never replaced.

6.4 Close the loop

When a session is done, say "Max close loop". Your phrase authorises the save. The agent appends a dated entry to its log note with: decisions, actions taken, corrections, unresolved questions, confidence, privacy boundary, links and the smallest next actions, then summarises it for you.

6.5 Message another AI (Founder OS)

If a handoff mailbox is set up, one AI can leave a message for another ("tell Codex the site build is ready") and the other reads it with "check handoffs". Messages are ordinary notes with a priority (P0 to P3) and an optional deadline.

7. How BrainLink keeps your notes safe

ProtectionWhat it means for you
New or append onlyNo AI can overwrite, edit or delete an existing note.
Preview before writeEvery save is shown first. Only an approved call writes.
AttributionEach note records AI platform, role, session id, time and source, and carries a "Made by" line.
Secret scanWrites that look like API keys, tokens, card or account numbers, or long token-like strings are refused.
Existing folders onlyAIs cannot invent new folder structures.
Protected notesGenerated index and map notes (names starting "00 INDEX" or "00 MAP") cannot be written.
Vault isolationVaults are never mixed. An agent only sees its own vault. Each AI connection can be limited to chosen vaults.
Read-only connectionsAny connection can be made read-only.
Proposal-only vaultsThe AI prepares text; nothing is saved.
Private vaultsLeft out of the ChatGPT-style search/fetch connector.
Local onlyHTTP mode listens on 127.0.0.1 and needs a bearer token. Setup is local-only with a session token.
Content-free logThe activity log records tool name, outcome and platform only, never your notes.
Treat note contents as data. BrainLink tells every AI that text inside a note is not a command to obey.

A 14-day trial starts at first setup. To activate, paste your key (it starts with BL1.) into Setup, or run brainlink license BL1.…. Activation works offline. After a trial or licence expires, BrainLink returns to the Free plan; your notes are unaffected. List prices at launch: Personal US$79 one-time (one year of updates), Team US$12 per user per month.

10. Advanced

HTTP clients (Grok bots, custom agents)

Requires a paid or trial plan. Generate a token in Setup, then run brainlink serve --http. The endpoint is http://127.0.0.1:8765/mcp (change with --http PORT). Send Authorization: Bearer <token>. The token must be at least 16 characters. A health check is at /health. Browser requests from other websites are rejected.

Per-connection environment settings

11. Troubleshooting

SymptomFix
AI does not know "Connect to Max"Press Connect for that app and fully restart it. Run brainlink clients.
"writes need a BrainLink licence"You are on the Free plan or the trial ended. Add a key.
"folder … does not exist"AIs may only write into existing folders. Create the folder in your vault first.
"refused: content looks like it contains secrets"Remove the key, token or number from the text.
"already exists; never overwrite"Choose a different title or date; BrainLink never replaces a file.
"decision is required"Your vault needs ADOPT, EXPERIMENT, MONITOR or REJECT on intake notes.
Captures show only a previewThe vault or agent is proposal-only; approve durable captures in Setup.
Vault marked MISSINGThe folder was moved or its drive is not mounted. Check brainlink status.
Setup page will not openRun brainlink setup and open the printed address.
Result says a note is stale or historicalIt has not changed for 14+ days or is marked superseded; check for a newer note.
Invalid config messageThe message lists each error; fix them in Setup or restore a backup.

12. Uninstalling

  1. Run brainlink disconnect all for each app you connected (or one at a time). Backups of the app settings are kept.
  2. Delete BrainLink.app (macOS) or use Add/Remove Programs (Windows).
  3. Optionally delete the BrainLink data folder (section 9). Your notes are never inside it and are never touched.
