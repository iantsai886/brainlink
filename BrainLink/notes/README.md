# Shared notes folder

This folder is an empty starter location for Markdown notes that an owner has approved for sharing through GitHub and BrainLink.

Before adding a note, check that its audience is allowed to read it. GitHub access applies to the whole repository, so BrainLink's per-agent filters cannot hide a file from someone who can read this repository directly. Keep credentials and private personal or client material out of shared repositories.

BrainLink can clone this folder separately from the application code. It does not assign a vault or Twin automatically; review the repository, branch, audience, and allowed folders in Setup first.
